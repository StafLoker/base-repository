# Licenses

Open source license templates.

## Files

- **`MIT`** — MIT License template

## Usage

1. Copy the template to your project root as `LICENSE`
2. Replace `<year>` with the current year
3. Replace `<name>` with your name or organization

## About MIT

The MIT License is a permissive license that:
- Allows commercial use
- Allows modification
- Allows distribution
- Allows private use
- Requires copyright notice inclusion
- Provides no warranty
