# READMEs

README templates for different project types.

## Files

- **`opensource-project.md`** — Complete template for open source projects

## Usage

1. Copy the template you need to your project root as `README.md`
2. Replace all placeholders (uppercase text and text within `<>`)
3. Add your images (logo, screenshots)
4. Customize sections according to your project

## Open Source Project Template

Includes:
- Header with logo, name, and slogan
- GitHub badges (downloads, version, license)
- Important alerts section
- Features list
- Installation instructions

Replace:
- `PROJECT NAME` — Project name
- `SLOGAN` — Project slogan
- `<url-repo>` — GitHub user/repository
- `SHORT DESCRIPTION` — Brief description
- Add your own sections as needed
